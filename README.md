# Browser Quiz

A group game of guessing popular web browsers that people use to access the internet, it doesn't give points so its up to you!

## Help

- Press `Next` and take a guess of the logo
- Then show Answer to so if your correct, play with yourself or as a group.
- Press `Enter` for Show Anwser

Enjoy and have fun!
